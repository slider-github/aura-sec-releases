# Aura-Sec — versiones publicadas

Solo binarios publicados de **Aura-Sec** (panel de seguridad local de Slider como fondo de pantalla). El código no está acá.

- Cada release trae `aura-sec.exe` y su **SHA-256**. Verificá el hash antes de instalar.
- Índice de la última versión: `https://updates.slider.cloud/aura-sec/latest.json`.
- Instalar / actualizar (PowerShell como administrador): `aura-sec.exe -instalar` · Quitar: `aura-sec.exe -desinstalar`.
